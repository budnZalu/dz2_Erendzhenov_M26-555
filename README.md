# Primitive DB

Автор: **Эрендженов (Erendzhenov)**. Группа: **M26-555**.

Учебный проект на Python 3.12 и выше. Реализован этап **«1. Подготовка»**:
устанавливаемый пакет `primitive_db` с консольной командой `project`,
интерактивным вводом через `prompt` и проверкой качества кода Ruff.

[Репозиторий проекта](https://github.com/budnZalu/dz2_Erendzhenov_M26-555).

Работа с таблицами, хранение JSON, PrettyTable, декораторы и кэширование
относятся к следующим этапам и пока не реализованы.

## Установка и запуск

Установите [uv](https://docs.astral.sh/uv/getting-started/installation/),
затем выполните в корне этого проекта:

```sh
uv sync
uv run project
```

Альтернативный запуск:

```sh
uv run python -m primitive_db.main
```

Для запуска без `uv run` можно активировать окружение:

```sh
source .venv/bin/activate
project
```

Пример работы:

```text
Первая попытка запустить проект!

***
<command> exit - выйти из программы
<command> help - справочная информация
Введите команду: help
<command> exit - выйти из программы
<command> help - справочная информация
Введите команду: exit
Выход из программы.
```

`help` повторно выводит справку, `exit` завершает программу. Пробелы вокруг
команды удаляются, пустой ввод запрашивается повторно. Неизвестная команда
выводит подсказку, после которой можно продолжить работу. Ctrl+C и конец
ввода (Ctrl+D в Unix) завершают программу без трассировки ошибки.

## Проверка качества кода

```sh
uv run ruff --version
uv run ruff check .
uv run ruff check src/primitive_db/engine.py
uv run ruff format --check .
```

Ruff установлен только как зависимость для разработки. Включены правила
`E`, `F`, `I`, максимальная длина строки 88 и целевая версия Python 3.12.

## Сборка и проверка метаданных

```sh
uv build
uvx twine check dist/*
```

В папке `dist/` появятся wheel и исходный архив. Команда `twine check`
проверяет метаданные локально и не публикует пакет на PyPI.

## Установка CLI из wheel

```sh
uv tool install dist/*.whl
project
```

Если в `dist/` остались сборки прошлых версий, укажите актуальный файл явно:

```sh
uv tool install dist/primitive_db-0.2.0-py3-none-any.whl
```

Если uv сообщает, что папка инструментов отсутствует в `PATH`, выполните
`uv tool update-shell` и перезапустите терминал.

## Структура проекта

```text
dz2_Erendzhenov_M26-555/
├── src/
│   └── primitive_db/
│       ├── __init__.py
│       ├── engine.py
│       └── main.py
├── .gitignore
├── .python-version
├── pyproject.toml
├── uv.lock
└── README.md
```

`__init__.py` пустой и служит маркером пакета. `main.py` содержит шебанг,
функцию `main()` и защиту `if __name__ == "__main__"`. Интерактивный цикл
реализован в функции `welcome()` модуля `engine.py`. Импорт модулей сам
по себе не запускает программу.

Окружение `.venv/`, сборки `dist/` и кэши исключены из Git.
